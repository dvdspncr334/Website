Save to GitHub (optional)

Commits the edited CSV to data/shop.csv with the GitHub API. Needs a fine-grained personal access token limited to this repository with Contents: Read and write. The token is only kept in this page's memory, is sent only to api.github.com, and is cleared after a successful commit. If you'd rather not use a token, click Download CSV and upload/commit the file yourself.

Recent user activity

Each signed-in visitor records their own email, last sign-in time and last activity time (at most every 15 minutes) in Firestore userActivity/{uid}. Only admins can read it. Users who haven't signed in since this was deployed won't appear.
